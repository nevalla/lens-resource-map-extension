# Changelog

What changed in each version of this extension, newest first.

## 2.0.0

Rewritten for the current Lens. On Lens 5 or 6, use 1.x.

- Resource Map of a cluster, opened from the cluster in the navigator: workloads, Services, Ingresses, ConfigMaps, Secrets, PersistentVolumeClaims and Helm releases, and how they relate.
- Namespace filter for the map, remembered per cluster.
- Resource Map section in the details panel of workloads, Pods, Services, Ingresses, ConfigMaps, Secrets and PersistentVolumeClaims.
